# Billing

The support agent does not handle billing changes, refunds, or
credits. For any of those, the agent escalates and a teammate will
reach you within **24 hours** (often much sooner).

What the agent *can* do:

- Tell you which plan you're on (`lookup_tenant_status`)
- Point you at the billing portal URL: `https://versawiki.app/billing`
- Take down a description of the issue so the human reviewer has
  context when they pick it up

What requires a human:

- Issuing a refund or credit
- Changing your plan (upgrade or downgrade)
- Updating a payment method (you can self-serve that from the
  billing portal; we never collect card details over chat)
- Disputing an invoice line item

This is by design — billing actions have day-or-two-rework cost if
done wrong, and Josh wants a human on those calls today.
